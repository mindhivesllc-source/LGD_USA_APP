# App Home Page UX

**Source:** https://shopify.dev/docs/apps/design/user-experience/app-home-page

## Required Polaris Components & Patterns
- Follow the **Homepage pattern** (Polaris template)
- Use **App nav** for support CTAs placement

## Purpose of App Home Page
A good home page must:
1. **Provide status updates** — quick statistics, system status
2. **Enable immediate actions** — respond to merchants' current needs
3. **Provide clear CTA buttons** — merchants can easily see what actions are available

## Design Requirements
- Answer merchants' questions quickly
- Convey available actions clearly
- Include: status updates, actionable information, statistics, graphs
- Should provide **daily value** to merchants

## What a Dashboard/Sync Page Should Look Like
Based on App Home guidelines:
- Cards with action buttons
- Dismissible informational banners
- Graphs/statistics showing performance data
- Sections for different functional areas
- Clear CTAs for primary actions

## Support Placement Rules
- Place support CTAs **consistently and discoverably** but **out of the way**
- Options for placement:
  1. Item in App nav
  2. Link in page footers
  3. Floating action button

## Hard Requirements for Design Compliance
- Must provide status updates on home page
- Must include clear CTAs showing available actions
- Support must be consistently discoverable
- Home page must provide daily value (not just a landing page)
