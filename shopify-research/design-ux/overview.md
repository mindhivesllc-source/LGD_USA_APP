# Design Guidelines Overview

**Source:** https://shopify.dev/docs/apps/design

## Required Polaris Components & Patterns
- Use **Polaris** — Shopify's unified design system for all app interfaces
- Use **Shopify App Bridge** for embedded admin apps (powers desktop, mobile, POS)
- Follow Polaris component library for all UI elements

## Core Design Principles
1. **Built for Shopify** — Meet Built for Shopify design requirements for App Store preferential treatment
2. **Adaptive** — Design for mobile-first; majority of store traffic is on mobile
3. **Better merchant experience** — Predictable UX that works like rest of Shopify admin
4. **Accessible** — Follow accessibility best practices throughout

## Layout Rules
- App must look native to Shopify admin (consistent spacing, header hierarchy, high-contrast background)
- Demonstrate "good faith effort" for high design quality bar

## Visual Design Requirements
- Match the appearance and behaviors of the Shopify host surface
- High-contrast background required
- Consistent spacing throughout

## navigation Must-Haves
- App navigation must be strictly configured per navigation guidelines

## Hard Requirements for Design Compliance
- Must achieve **Built for Shopify** status for App Store preferential treatment
- Must use App Bridge for embedded admin apps
- Must follow Polaris design system conventions
- Must meet accessibility best practices
